# UNIDAD 11: Estadística
La estadística es la ciencia que se encarga de recoger, organizar y analizar datos para realizar cálculos y representar la información mediante gráficos y tablas

## 1. Recogida y Organización de Datos
El principio de todo estudio de estadistica empieza recopilando datos aqui te enseño como se llama cada cosa para que te introduzcas:
### A. Conceptos
- Población: Es el conjunto entero de todos los elementos que quieres investigar
- Muestra: De todo ese conjunto (Población) vas a coger a cada uno y los vas a investigar
- Tamaño Muestra: Es el total de todas las muestras.
> **Ejemplo:** Si quieres investigar la nota media en Matemáticas de todos los alumnos de España (Población), seleccionamos un grupo de 100 alumnos de varios institutos para hacer la prueba (Muestra, N = 100).

### B. Tipo de Variables
La variable es la propiedad que vas a preguntar a cada individuo (muestra),
1. Variable Cualitativa: Mide cualidades o categorías no numéricas, que sean en letras, como color de ojos, colores...
2. Variable Cuantitativa: Mide cantidades numéricas, estas se dividen en dos secciones
   - Discreta: Son números enteros como número de hermanos, goles...
   - Continúa. Son números que tienen intervalos como la estatura, peso, medidas...
En resumen, se divide en números y no números. Los números se dividen en dos: si son números enteros o decimales.

## 2. Tabla de Frecuencias
Para organizar los datos y facilitar los cálculos, utilizamos la **Tabla de Frecuencias**

- Dato/Variable (*Xi*): Es el valor que estamos estudiando
- Frecuencia Absoluta (*fi*): Es el número de veces que se repite ese mismo valor. La suma de todas se pone N
- Frecuencia Relativa (*hi*): Es la variable dividida entre la suma de todas las frecuencias absolutas. Fórmula: *fi*/N=*hi*
- Porcentaje relativo %: Es la Frecuecia Relativa · 100. Fórmula: *fi*·100 = Porcentaje de dato en total.
- Grados del sector (°): Es la Frecuecia Relativa · 360. Fórmula: *fi*·360 = Grados
> Ejemplo
Imagina que le preguntamos a un grupo de amigos cuántos hermanos tienen y nos responden esto:  
`1, 2, 1, 0, 1, 2, 0, 1`  *(N = 8 personas).*

Así es como construimos la tabla de frecuencias bien organizada:

| *xi* | *fi* | *hi* | % | ° |
| :---: | :---: | :---: | :---: | :---: |
| **0** | 2 | 0,25 | 25% | 90°|
| **1** | 4 | 0,5 | 50% | 180°|
| **2** | 2 | 0,25 | 25% |90° |
| **TOTAL** | N=8| 1,00 | 100% | 360°|

## 3. Representación Gráfica
Una vez organizados los datos, se representan visualmente:
* Diagramas de Barras/histogramas: En el eje X (Horizontal) ponemos las Variables (*xi*) y en el eje Y (Vertical) ponemos las Frecuencias Absolutas(*fi*)
* Diagramas de Sectores: Círculo dividido en porciones proporcionales a los grados (°) calculados.

## 4. Medidas de Centralización
Son valores numéricos que resumen el conjunto de datos en un punto central representativo:

### A. Media Aritmética
Es el valor promedio que se obtiene al hacer un reparto equitativo de todos los datos
El simbolo de **Media Aritmética** = x&#773;

La formula de la **Media Aritmética** = <p align="center">
  &sum;(x<sub>i</sub> &middot; f<sub>i</sub>)<br>
  ─────────<br>
  N
</p>

### B. La Moda
La **Moda** es el dato que más Frecuencia Absoluta(*fi*) tiene de todas.
- El simbolo de Moda = *Mo*

### C. La Mediana
La **Mediana** es el valor que ocupa la posición central exacta cuando ordenamos todos los datos de menor a mayor
- El simbolo de Mediana = *Me*
